# OpenSandbox 1.1.0-rc.1

1.1.0 版本线的候选版本，也是统一伞形发布流水线（OSEP-0016）的首次端到端演练。它携带了跨 chart 和镜像引用到 `1.1.0-rc.1` 的版本提升；不包含任何功能性变更。rc 发布不交付 SDK 制品 —— SDK/CLI 软件包、依赖范围和身份常量将随 1.1.0 稳定版本提升而更新。请测试发布机制 —— staging 镜像构建、BOM 组装和被暂扣软件包的扇出 —— 并报告问题。

## 亮点

- 1.1.0 版本线上的首个伞形发布候选
- 平台版本对齐到 `1.1.0-rc.1`（chart 与镜像引用）

## 其他（Misc）

- release: bump platform version to 1.1.0-rc.1 (#1896)

## 升级与兼容性

- 镜像：`opensandbox/<component>:release-1.1.0-rc.1`（全部三个仓库）
- 软件包：不变 —— SDK/CLI 制品在 1.1.0 稳定发布时发布
- Chart：从该标签渲染（`helm template ./manifests/charts/opensandbox`）
- Kubernetes：支持范围 v1.21 – v1.34（chart 声明 `kubeVersion: ">=1.21.1-0"`）
- 版本偏差：server ↔ CLI/SDK 同一版本线受支持；±1 个 minor 会告警

## 制品

- 镜像：`opensandbox/<component>:release-1.1.0-rc.1`（Docker Hub / GHCR / ACR）

## 安装

```bash
# Platform (Kubernetes) — render the chart at this tag and apply
git clone https://github.com/opensandbox-group/OpenSandbox
git checkout release-1.1.0-rc.1
helm dependency build manifests/charts/opensandbox  # package file:// sub-charts (not committed)
helm template ./manifests/charts/opensandbox | kubectl apply -f -
```

对照 BOM 验证你安装的内容：参见[发布验证](/community/release-verification)。
